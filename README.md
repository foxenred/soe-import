# Агентное управление S&OE-циклом импорта

Аналитический отчет и имитационная модель к кейсу «Мультиагентный S&OE-цикл импорта» (Logus Nova 2026).

**Отчет:** [analysis/REPORT.md](analysis/REPORT.md) — текст и графики,
[analysis/report.ipynb](analysis/report.ipynb) — тот же отчет с кодом.

> **Все данные модельные.** Расположение 41 регионального РЦ взято из открытых источников, все остальное синтетическое:
> спрос, сроки, документы, экономика. Импорт приходит в федеральный транспортный центр (федеральный ТЦ) и уходит
> регионам по их заявкам. Результаты — только в относительных величинах.
>
> **ИИ-агенты используют LLM GigaChat от Сбера** (GigaChat API). Она читает письма, PDF и документы и объясняет
> решения, но чисел не считает: прогноз сроков и расчет рычагов делают ML-модели и оркестратор. В варианте «Агенты без
> LLM» агенты работают без нее. Дальше — просто LLM.

## Что сравниваем

| Вариант | Как устроен |
|---|---|
| S&OE без агентов | контейнер не закреплен за регионом; товар лежит общим запасом в федеральном ТЦ и уходит регионам по их заявкам; заявки составляют региональные планировщики, данные о грузах собирают и решения готовят люди вручную |
| Агенты без LLM | заявку региона составляет агент региона по прогнозу спроса, сроки прогнозирует ML, рычаги считает оркестратор по сценариям прихода грузов; агенты читают только структурированные данные и документы стандартной формы |
| Агенты с LLM | то же, плюс LLM читает письма, поток статусов и документы любой формы |

Штат людей одинаковый, стоимость работы агентов вычтена, экономия на персонале не считается. 500 вариантов спроса и
задержек на каждый режим; в одном варианте все три способа управления видят одни и те же события.

## Главное

- С агентами прибыль потока импорта выше на **2,8 %** в обычном режиме, на **4,7 %** при
  загрузке терминалов 2026 года и на **2,9 %** при сбое. Агенты в плюсе в 98 % вариантов.
- Продаж теряется на 35 % меньше. Эффект в 27 раз больше стоимости работы агентов.
- Даже если у S&OE без агентов планировщиков сколько угодно, агенты дают еще +1,1 % прибыли.
- Оценка рычага по 16 сценариям прихода вместо одного срока дает +0,6 %.
- LLM дает 3 % эффекта агентов в обычном режиме, 6 % при загрузке 2026 года и
  38 %, когда товар приходит впритык к продажам.
- Главный рычаг — приоритетный вывоз с СВХ (65 % эффекта); его цена — допущение.

## Структура

| Папка | Что |
|---|---|
| `analysis/` | отчет: `REPORT.md`, `report.ipynb`; сборка (`build.py`), оформление (`style.py`), разборы (`lib.py`, `charts.py`) |
| `src/v5/` | модель: сеть РЦ (`network.py`), ML-сроки (`eta.py`), имитация (`sim.py`), эксперименты (`experiments.py`), сводка (`report.py`) |
| `src/` | общие функции (`common.py`), параметры (`config.py`) |
| `agents/` | агенты с LLM (GigaChat API): инструменты (`tools.py`), оркестратор (`orchestrator.py`), проверка чисел (`numbers.py`), запись разбора (`record.py`, `recordings/`) |
| `config/params.yaml` | все параметры: факт — с источником, допущение — с пометкой и диапазоном |
| `data/` | модельная сеть РЦ, точки входа, контуры округов |
| `outputs/model_v5/` | результаты: `results.json`, по вариантам — `runs.csv`, `runs_staff.csv` |
| `docs/sources.md` | источники по таможне, СВХ и срокам |
| `tests/` | баланс штук, одинаковые события у всех вариантов, калибровка ML-сроков, рычаги без знания будущего |

## Как воспроизвести

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q tests
.venv/bin/python -m src.v5.experiments                 # results.json и runs.csv, около часа на 8 ядрах
.venv/bin/python -m src.v5.experiments --staff-check   # runs_staff.csv, около минуты
.venv/bin/python -m analysis.build                     # report.ipynb и REPORT.md, около минуты
```

Зерно генератора фиксировано (`config/params.yaml`, `seed`), результаты воспроизводятся.

Разбор контейнера агентами с LLM (GigaChat API): ключ — в `.env` (образец — `.env.example`), затем
`.venv/bin/python -m agents.record K-382`. Без ключа агенты работают по правилам с той же логикой.
